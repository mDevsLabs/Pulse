# mAI Pulse - Extension VS Code

Cette extension apporte l'expérience **mAI Pulse** directement au cœur de Visual Studio Code.

## 🚀 Fonctionnalités
- **Panneau latéral dédié** dans la barre d'activité
- **Vue plein onglet** pour travailler en grand écran
- **Bouton de rafraîchissement rapide**
- Support complet du thème sombre/clair de VS Code
- Integration fluide du site [https://mai-officiel.vercel.app](https://mai-officiel.vercel.app)

## 📦 Installation & Compilation

```bash
# Se placer dans le dossier apps/vscode
cd apps/vscode

# Installer les dépendances
npm install

# Build
npm run build

# Générer le fichier .vsix
npx @vscode/vsce package
```
